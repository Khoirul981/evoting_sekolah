## Skenario Tugas Praktik Demonstrasi

### **Kelompok Pekerjaan 1: Melakukan perancangan aplikasi berbasis mobile**

**Unit Kompetensi:**

| No. | Kode Unit | Judul Unit |
| :---: | :--- | :--- |
| 1. | J.612000.001.01 | Menunjukkan platform sistem dan bahasa pemograman di dalam perangkat lunak |
| 2. | J.612000.007.01 | Merancang mobile interface |

**Skenario Tugas Praktik Demonstrasi:**
* Tentukan dan tunjukkan platform sistem serta bahasa pemrograman utama yang digunakan.
* Rancang antarmuka pengguna menggunakan perangkat lunak desain (*design tools*) pilihan Anda sebelum masuk ke tahap pengkodean.

**Perlengkapan dan Peralatan:**
* Software design
* Media presentasi sesuai kebutuhan

**Durasi Waktu:** 180 Menit

---

### **Kelompok Pekerjaan 2: Melakukan analisis dan kebutuhan**

**Unit Kompetensi:**

| No. | Kode Unit | Judul Unit |
| :---: | :--- | :--- |
| 1. | J.620100.001.01 | Menganalisis tools |
| 2. | J.620100.003.01 | Melakukan identifikasi library, komponen atau framework yang diperlukan |

**Skenario Tugas Praktik Demonstrasi:**
* Lakukan analisis terhadap pustaka (*library*), kerangka kerja (*framework*), dan komponen pihak ketiga yang akan diintegrasikan ke dalam sistem.
* Dokumentasikan alasan pemilihan alat pengembangan agar sesuai dengan kebutuhan fungsional aplikasi.

**Perlengkapan:**
* Dokumen spesifikasi kebutuhan perangkat lunak

**Durasi Waktu:** 30 Menit

---

### **Kelompok Pekerjaan 3: Melakukan perancangan**

**Unit Kompetensi:**

| No. | Kode Unit | Judul Unit |
| :---: | :--- | :--- |
| 1. | J.620100.004.02 | Menggunakan struktur data |
| 2. | J.620100.005.02 | Mengimplementasikan user interface |
| 3. | J.620100.007.01 | Mengimplementasikan rancangan entitas dan keterkaitan antar entitas |

**Skenario Tugas Praktik Demonstrasi:**
* Terapkan struktur data yang efisien di dalam fungsi (*function*) atau metode (*method*) program.
* Tampilkan relasi antar table yang ada di database anda.
* Pastikan aplikasi memiliki fitur manipulasi data dasar (Create, Read, Update, Delete) yang berfungsi penuh.

**Perlengkapan dan Peralatan:**
* DBMS
* Perangkat lunak yang anda buat

**Durasi Waktu:** 30 Menit

---

### **Kelompok Pekerjaan 4: Menulis kode sumber**

**Unit Kompetensi:**

| No. | Kode Unit | Judul Unit |
| :---: | :--- | :--- |
| 1. | J.620100.010.01 | Menerapkan perintah eksekusi bahasa pemograman berbasis teks, grafik dan multimedia |
| 2. | J.620100.011.01 | Melakukan instalasi software tools pemograman |
| 3. | J.620100.012.01 | Melakukan pengaturan software tools pemrograman |
| 4. | J.620100.014.01 | Menerapkan metode dan praktik penggunaan kembali (reusable) subrutin - subrutin |

**Skenario Tugas Praktik Demonstrasi:**
* Lakukan instalasi serta konfigurasi perangkat lunak pendukung (tools/plugins) yang diperlukan untuk menjalankan lingkungan pengembangan. (jika sudah ter-instal, anda hanya perlu menunjukkan spesifikasi dan kegunaan dari tools/plugin yang anda gunakan)
* Terapkan perintah eksekusi bahasa pemrograman yang mencakup elemen teks, grafik, maupun multimedia sesuai desain. (maksudnya adalah bisa menampilkan teks, grafik (icon), dan juga upload file gambar seperti png, jpg dll.)
* Susun dokumentasi mengenai:
  * Struktur data tabel database.
  * Software tools yang digunakan.
  * Tunjukkan penggunaan function/method dalam aplikasi anda.

**Perlengkapan:**
* Dokumentasi tools/plugin yang digunakan
* Dokumentasi struktur data tabel database

**Durasi Waktu:** 120 Menit
